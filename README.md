# Automotriz Mimi

Sitio web informativo y responsivo diseñado para el taller mecánico **Automotriz Mimi**. El proyecto presenta los servicios del taller, su equipo de trabajo y los canales de contacto mediante una interfaz clara, ligera y fácil de mantener.

## Funcionalidades principales (Features)
1. **Diseño 100% responsivo:** Adaptación automática a dispositivos móviles, tabletas y computadoras de escritorio mediante cuadrículas flexibles (`CSS Grid`).
2. **Navegación fluida:** Barra de navegación accesible con desplazamiento suave (`scroll-behavior: smooth`) entre las secciones de inicio, servicios, equipo y contacto.
3. **Catálogo de servicios automotrices:** Presentación visual organizada por tarjetas con los principales servicios técnicos del taller.
4. **Sección "Conoce a nuestro equipo":** Perfiles individuales con fotografía, nombre, cargo y descripción de responsabilidades de cada especialista, incluyendo respaldo visual automático ante fallos de carga de imagen.
5. **Sección de contacto y ubicación:** Bloque informativo con horarios de atención, teléfono, dirección y llamada a la acción directa para agendar citas.

## Stack Tecnológico
* **HTML5:** Estructura semántica (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **CSS3:** Estilos personalizados en un único archivo mediante variables nativas (`:root`), Flexbox y CSS Grid, sin dependencia de frameworks externos.

## Estructura de carpetas
El proyecto mantiene una arquitectura minimalista y autocontenida para facilitar su despliegue y comprensión:

    automotriz-mimi/
    │
